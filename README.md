# 🐾 PetShop
 
Aplicação web de pet shop desenvolvida como projeto acadêmico, com foco em uma experiência responsiva para apresentar serviços e categorias de produtos para animais de estimação.
 
🔗 **[Acessar o projeto online](https://petshop-rho-rouge.vercel.app/)**  
💻 **[Repositório no GitHub](https://github.com/petshop-cp/petshop)**
 
## 📋 Sobre o projeto
 
O **PetShop** é uma aplicação front-end construída em equipe. O projeto utiliza componentes React, navegação com React Router e estilização com Tailwind CSS para criar uma interface adaptável a diferentes tamanhos de tela.
 
## 🛠️ Tecnologias utilizadas
 
- **React 19** — construção da interface em componentes.
- **Vite 8** — ambiente de desenvolvimento e build.
- **Tailwind CSS 4** — estilização responsiva.
- **React Router DOM 7** — gerenciamento de rotas.
- **JavaScript** — lógica da aplicação.
- **ESLint** — padronização e verificação do código.
 
## 🚀 Como executar localmente
 
### Pré-requisitos
 
- Node.js compatível com o Vite 8 (Node.js 20.19+ ou 22.12+).
- npm instalado.
 
### Instalação
 
```bash
git clone https://github.com/petshop-cp/petshop.git
cd petshop
npm install
npm run dev
```
 
Abra no navegador o endereço exibido no terminal (normalmente `http://localhost:5173`).
 
> Execute os comandos na pasta que contém o arquivo `package.json`.
 
## 📜 Scripts disponíveis
 
| Comando | Descrição |
| --- | --- |
| `npm run dev` | Inicia o servidor de desenvolvimento. |
| `npm run build` | Gera a versão de produção. |
| `npm run preview` | Visualiza localmente a build de produção. |
| `npm run lint` | Executa as verificações do ESLint. |
 
## 📱 Interface
 
O projeto foi pensado para apresentar conteúdos de um pet shop de forma clara, com layout responsivo. A página inicial inclui seções voltadas à apresentação de serviços e categorias.
